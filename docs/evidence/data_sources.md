## Portal and access note

The primary open data portal named in Charter Addendum 01 is bayanat.ae
(Federal Competitiveness and Statistics Centre). Attempts to access the
Bayanat REST API on 2026-08-19 returned HTTP 302 redirects to
`/en/error/404` for all dataset listing and resource endpoints. The portal
is a Sitecore SPA that requires antiforgery tokens generated by browser
JavaScript; unauthenticated server-side calls are rejected. The exact
failure is documented in `docs/DATA_REQUESTS.md` with the precise endpoints
tried. Bayanat datasets are requested for operator fetch.

Datasets below are sourced from the Ajman Open Data Portal (data.ajman.ae),
which the charter explicitly names as an authorised source and which exposes
an unauthenticated Opendatasoft Explore API v2.1. All datasets are published
under CC BY 4.0 and are UAE government open data. The portal assigns each
dataset a `dataset_uid` (format: `da_XXXXXX`); this identifier is recorded
as the Resource GUID equivalent for each binding.

data can be evaluated on whether it correctly names services, reports correct
fees, and handles the Arabic terminology that citizens would use. The dataset
grounds control C-CTL-001 (Arabic language accuracy) and C-CTL-002
(government service knowledge) weight calibration directly: if the model
cannot match these 60 services correctly in Arabic it fails the knowledge
control, and if it invents fees not in this dataset it fails the accuracy
control. A dataset that merely lists government services in English would not
ground this use case; the bilingual structure is what makes this dataset
specifically useful.
